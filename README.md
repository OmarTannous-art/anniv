# Months Scroll Website

An animated website that displays the 12 months of the year in a vertical scrolling layout. Each month takes up the full viewport height with a unique gradient background, large graphics, and descriptive text. As you scroll, content fades in smoothly for an engaging experience.

## Features

- Scroll-snap navigation for viewing one month at a time
- Fade-in animations triggered by scroll
- Large placeholder images for each month
- Responsive design

## How to View

Open `index.html` in your web browser. Scroll down to navigate through the months. The page will snap to each month section.

## Files

- `index.html`: The main HTML structure with month content
- `styles.css`: CSS for layout, colors, and animations
- `script.js`: JavaScript for scroll-triggered animations
